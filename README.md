# 🧠 OpsHub

**OpsHub** é um painel interativo em arquitetura **MERN (MongoDB, Express, React, Node.js)** com integração **DevOps**.  
Seu objetivo é demonstrar domínio em desenvolvimento fullstack aliado à automação e infraestrutura moderna.

---

## 🚀 Visão Geral

O projeto servirá como portfólio técnico completo, unindo:
- Backend escalável (Node.js + Express)
- Frontend moderno (React + Vite)
- Banco de dados não relacional (MongoDB)
- Containers Docker e CI/CD simulados
- Integração de métricas e monitoramento simulados
